# 운영 대시보드 개편과 행사 첫날 화면 손질

행사 첫날(금) 오후, 데스크 운영 중에 화면을 보며 고쳤다. 대시보드 한 덩어리와 참가자 화면 잔손질 여러 건.
같은 저장소에서 **다른 세션이 동시에 작업**하고 있어(QR·갤러리·명단 필터), 내 파일만 골라 커밋했다.

## 한 것

### 운영 대시보드 (`/admin`) — `bd988a6` + 마이그레이션 0044~0048

| 전 | 후 |
| --- | --- |
| 5초 폴링 · 승인된 사람만 셈 | **1초 폴링** · **명단 전체**를 셈 (승인 여부 무관) |
| 체크인·미도착·숙소·승인대기 4칸 | 전체 인원 · 체크인 · 금요일 도착 · 토요일 도착 · 시스템 가입 · 미가입 6칸 |
| 숫자 하나 | 칸마다 `{all, members, pastors, mentors}` — 아래 줄에 「지체 80 / 108 · 교역자 2 / 4 · 멘토 5 / 8」, **0/0인 갈래는 숨김** |
| 미도착 명단 60명 | 뺌 — 참가자 탭에서 거르면 된다 |
| 최근 체크인 8명 (이름·방) | 체크인 피드 60명 — 방·조·**방장/조장**·티셔츠·강의(멘토) 신청을 칩으로 |

- 도착 요일: 지체는 시트의 `arrive_day`에 `(금)`·`(토)`가 든 것으로, **교역자는 금요일·멘토는 토요일**로 센다(신청서가 없어 요일이 비어 있다).
- 시스템 가입 = 소셜 계정을 연결한 사람(`auth_user_id`). 승인 기준으로 세면 55/55라 아무 말도 못 한다.
- 유형이 비어 있으면 지체 — `null in (...)`이 null이라 `coalesce`/`case`로 갈랐다.
- 마이그레이션은 0044 → 0045(명단 전체) → 0046(방장·조장) → 0047(세 갈래) → 0048(요일)로 쌓였다. 전부 `create or replace`라 **0048 하나만 돌려도 최신**이다.

### 말씀카드 — `831c244` `16137a2` `b376562` `cfd5ac2` `2e0c6a6` `8ad1744` `c57d189` `5984580` `95cd371`

- 폰 배경: 구절·말씀·소속 간격을 좁혀 소속 줄이 산 능선에 닿지 않게 (`ref_top .294→.290 · verse_top .3829→.360 · foot_top .570→.528`, 여유 50px → 160px). 44장 모두 3줄 이하라 겹칠 일 없음을 세고 나서 옮겼다.
- 정사각: 그림 둘레 2px 검정 선 제거. 화면의 1px 선과 탭 검정 채움도 뺐다.
- 저장: iOS만 공유 시트(「이미지 저장」이 사진 앱으로 가는 유일한 길), 안드로이드·PC는 바로 내려받기. 저장되면 토스트 「저장되었습니다」 1.2초 — 폰에서는 탭바 위로.
- 5x7·폰배경 미리보기는 정사각과 같은 높이 — `.wc-stage`에 `container-type: inline-size`를 두고 `100cqw`로 잰다.

### 내 정보 — `43ebb59` `005ff03` `d0457a5`

- 카드 제목 「MY ROOM/MY TEAM」 → 「숙소/조」, 공개 전 문구 「아직 공개 전이에요」 한 줄.
- **체크인 전에는 QR만**, 체크인되면 숙소·조·말씀카드가 열린다. QR 카드가 5초마다 체크인을 물어 `router.refresh()`하므로 참가자가 새로고침할 필요 없다.
- 「체크인 완료」 카드는 내렸다 — (※ 같은 날 다른 세션 `53afea6`에서 티셔츠 크기를 적으며 **되살림**. 현재는 완료 카드 + 숙소·조·말씀카드가 함께 보인다)

### 폰 레이아웃 — `50495d6`

- 폰에서 일정표 탭·갤러리 격자·정보 격자·영상·지도·내 정보 카드를 좌우 여백 밖으로 밀던 규칙(`margin: 0 calc(var(--gutter) * -1)`) 블록을 통째로 뺐다. 타임테이블·방명록은 본문 폭이라 둘이 섞여 어긋나 보였다.
- 앱 설치 안내에서 PC 탭 제거 — iPhone·Android만.

## 판단

- **폴링을 Realtime으로 바꾸지 않았다.** 보는 사람은 운영진 몇 명, SWR은 탭이 뒤로 가면 멈춘다. Realtime은 RLS·채널·재연결이 붙어 행사 당일 디버깅 위험이 더 크다.
- **체크인 이력 테이블을 만들지 않았다.** `checked_in_at` 하나로 최근 순 피드를 세우고, 취소하면 피드에서 빠지는 것이 오히려 맞다는 결정.
- 다른 세션의 스테이징이 섞인 공유 파일(`admin.css`·`types.ts`)은 **임시 인덱스**(`GIT_INDEX_FILE` + `hash-object` + `commit-tree`)로 내 덩어리만 떼어 커밋했다. 그쪽 스테이징은 그대로 남겼다.

## 배운 것

- 화면이 `undefined`투성이면 프론트와 DB 함수의 응답 모양이 어긋난 것 — 마이그레이션을 아직 안 돌린 상태. 함수가 `create or replace`라 SQL Editor에서 돌리면 다음 폴링에 바로 맞는다.
- `--ink-40` 변수가 CSS 세 곳에서 쓰이는데 정의가 없었다. 정의를 넣어 hover 색이 살아났다.
- 로컬에 DB 접속 정보가 없어(공개 키뿐) 마이그레이션은 **사용자가 SQL Editor에서** 돌린다. 내가 검증할 길이 없으니 SQL은 정독하고 `null` 비교부터 의심한다.

## 남은 것

- 그래프 색 그룹에 `MIRACLE 2026` 계열을 넣지 않았다 — Obsidian이 켜져 있어서. 끈 뒤에 그래프 색 구성 절차대로.
- 폰 실기기에서 세 탭(정사각·5x7·폰배경) 높이가 같은지, 갤러리·홈 아래쪽 블록이 본문 폭에 맞는지 미확인 (로그인 화면이라 브라우저 자동 확인 불가).
