## 검증

```bash
npm test && npm run lint && npm run build
```

- **테스트**는 순수 함수에만 있다 — 명단 CSV 파싱, 생년월일·전화번호 정규화,
  YouTube ID 추출, 사이트 설정 파싱. 전부 *조용히 틀리면 사람이 누락되는* 종류다.
- **빌드 출력의 `○`/`ƒ` 표시**를 함께 볼 것. 참가자 페이지가 `ƒ`(동적)로 바뀌었다면
  어딘가에서 `cookies()`를 부른 것이고, 그러면 prefetch가 죽는다
  → [11. 렌더링](11-rendering.md) §2
