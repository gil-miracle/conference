# 강사 사진

이 폴더에 아래 파일명으로 넣으면 강사 카드·상세 페이지에 자동으로 연결된다.
파일이 없으면 `PHOTO` 자리 표시가 나오므로 화면이 깨지지는 않는다.

| 파일명 | 강사 |
|---|---|
| `cho-youngchan.jpg` | 조영찬 전도사 |
| `choi-jaeyoon.jpg` | 최재윤 목사 |
| `yoo-kisung.jpg` | 유기성 목사 |
| `lee-jaehoon.jpg` | 이재훈 목사 |

- **정사각(1:1)** 으로 잘라서 넣는다. 카드가 정사각 비율을 쓴다.
- 권장 크기 800×800 이상, 1500×1500 이하. JPG 품질 80 정도면 충분하다.
- 파일명을 바꾸려면 [src/lib/content.ts](../../src/lib/content.ts)의 `SPEAKERS[].img`도 함께 고친다.
